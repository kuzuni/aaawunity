필수 스타일 원본은 https://raw.githubusercontent.com/kuzuni/aaawunity/main/Assets/Art/ChihuahuaEquipmentThemes/Reference/character_base.png 이다. 파일로 받아 직접 눈으로 확인한 뒤 모든 내장 이미지 생성/편집 호출에 참고 이미지로 첨부한다. 노란 치와와의 큰 곧은 귀, 크림색 눈썹/주둥이/귀 안쪽, 큰 갈색 눈, 갈색 코, 오른쪽을 보는 귀여운 정체성 유지. 굵고 매끈한 검은 외곽선, 둥근 단순 형태, 밝은 색면과 약한 명암, 작은 크림색 하이라이트. 사실적인 질감/붓터치/복잡한 애니 채색/과한 빛 금지. imagegen 스킬과 내장 생성 도구를 사용하며 유료 API/CLI로 전환하지 말 것. 먼저 저장소 읽기와 실제 이미지 도구 사용 가능 여부를 확인하여 짧게 보고한 뒤 제작을 계속한다. unavailable이면 구체적인 제한과 확보한 파일을 남기고 생성했다고 주장하지 말 것.

소품/아이콘은 진짜 투명 RGBA PNG, 전체 모양이 잘리지 않게 여백 확보. 배경이 체크무늬로 그려진 RGB는 통과 아님. 알파 채널과 가장자리, 원본 스타일을 직접 검사한다. 글자/워터마크를 이미지에 그리지 않는다. 서로 다른 자산을 한 장짜리 시트로 대체하지 말고 개별 파일로 납품한다. 생성 결과는 즉시 작업 폴더에 저장하고 2~3개마다 짧은 CHECKPOINT.md, 프롬프트, SHA256/크기/mode/alpha extrema/검수 여부가 든 manifest.json 및 {카탈로그 키: 실제 Assets 경로} catalog-fragment.json을 갱신한다. 툴 출력이나 거대한 문서를 대화에 전부 펼치지 말 것. 실패한 전송은 원격 상태를 먼저 확인하며 재시도는 최대 3회. 새 세션에서 파일만 읽고 이어받을 수 있도록 완료/남은 항목을 정확히 적는다.

납품은 아래 전용 브랜치와 전용 폴더에 작은 단위 커밋/push로 보존(가능한 연결된 GitHub 도구 사용, non-force; 다른 브랜치/파일을 덮어쓰지 않는다). push 기능이 없으면 모든 산출물과 재개 문서를 포함한 다운로드 가능한 ZIP을 만들고 실제 링크를 제공한다. 승인된 범위의 아트 제작을 계속 끝내며 단순 계획/프롬프트만 납품하지 말 것. Unity 연결과 화면 검증은 부모가 수행하므로 전체 TODO 완료로 표시하지 않는다.
