# 레퍼런스 레이아웃 실측표 (T116 · 자)

> **채점 = `tools/ui_score.py <화면> [layout.json]`** (T46 · ROUTINE §5). 게임 쪽 % 는 PlayMode `UiShotsTests` 가 활성 `UiTag`(`UiKit.Tag(t, "요소 이름")` · «줄(N칸)» 은 `UiKit.TagGroup` 의 합집합)를 재서 `screens` 브랜치의 `layout.json` 에 쓴다 — 이름표는 이 표의 «요소» 열과 **글자까지 같아야** 한다. ①~⑦ 은 `ui_score.py` 의 SCREENS 표가 화면(01_lobby · 02_battle · 06_gear · 07_gear_detail · 08_gear_fuse · 09_shop_1/10_shop_2 · 04_perks/05_perks_list)에 고정 매핑 · **새 화면 표는 «## ⑨ 화면 이름 — `NN_name.jpg`» 형식으로 이 파일에 추가**(⑧ 공통 표는 화면이 아니다 · 제목의 백틱 파일명 `NN_` 접두로 찾는다). 아래 하니스 이야기(`tools/t3/shots.js` · CSS 선택자)는 aaaw(HTML) 것 — 규약(⊕ 합집합 · «(참고·컨테이너)» 제외 · ±3%p)만 그대로 쓴다.

> **⚑ 주인 지시(12:0X·12:1X) — 채점은 배치·비율·비례만.** 이 표가 «자» 다. 회차 워커도 비평가도
> 이 표의 % 와 `tools/t3/shots.js` 가 낸 `layout.json` 의 % 를 나란히 놓고 **±3%p(프레임 기준)** 로 판정한다.
> 색·폰트·아이콘·그림체는 **이 표에 없다** — 점수 밖이기 때문이다.
>
> **재는 법** — 레퍼런스 jpg 는 전부 **1080×2340**(9:19.5)이고 게임 프레임은 **390×844**(9:19.5 아님, 9:19)다.
> 두 화면 모두 **프레임 좌상단 0% · 우하단 100%** 로 환산해 비교한다(절대 픽셀이 아니라 비례를 본다).
> 이 표의 수치는 U01 워커(sess-1150-20326 / D)가 5% 격자를 얹은 이미지에서 읽은 값이고, **±0.5%p 정도의
> 판독 오차**가 있다(격자 한 칸이 세로 5% = 117px). 표가 틀렸다고 보이면 고치되 **회차 로그에 적는다**(ROUTINE ⑥).
>
> 표기: `x` = 왼쪽 모서리, `y` = 위쪽 모서리, `w`·`h` = 폭·높이. 전부 프레임 대비 %.

## ⚑ U02 회차 정정 (레퍼런스 % 는 그대로 · «게임 쪽을 어떻게 적는가» 의 정정 2건)

### ⓐ CSS 에 «프레임 %» 를 적을 때는 0.9755 로 나눈다 — `--fh` 는 프레임 높이가 **아니다**

U01 이 신설한 `--fh` 는 `min(100dvh, 100vw*19/9)` 인데, `#frame` 은 `height:100dvh` · `width:min(100vw, 100dvh*9/19)` 라
**잘리는 쪽은 높이가 아니라 폭**이다. 그래서 9:19.5 인 390×844 에서 `--fh = 823.3px` 이고 프레임 높이 844px 보다
**2.45% 작다**(360×800 이면 5%). 즉 `calc(var(--fh)*.28)` 은 프레임의 28% 가 아니라 **27.3%** 다.

- 지금 이 레포의 세로 값들은 **390×844 에서 실측으로 맞춘 것**이라 그 폭에서는 표와 맞는다.
- 새 값을 적을 때 규칙: **`calc(var(--fh) * (목표% ÷ 100 ÷ 0.9755))`** (예: 프레임 28% → `.287`).
- **U03 후보 과제**: `--fh:100dvh` 로 바로잡고 세로 값 전부를 ÷1.0251 로 되돌리면 어떤 기기에서도 표대로 선다.
  전 화면이 한꺼번에 움직이므로 **다른 수정과 섞지 말고 한 회차를 통째로 쓰는 편이 안전하다.**

### ⓑ 하니스가 못 재던 행 — 이제 표와 1:1 이다

U01 이 `tools/t3/shots.js` 에 적어 둔 gearpop 선택자 4개(`.gd-ic`·`.gd-contrib`·`.gd-opts`·`.gd-cost`)는
**실재하지 않는 클래스**였고, 상점 «섹션 헤더1» 은 `.shop-sec:first-child{display:none}` 때문에 늘 null 이었다.
