## 공통 문법 (모든 화면에 반복되는 것 — 먼저 한 번 만들고 재사용)

- **상단 재화 바**(로비·장비·상점·펫·던전·아레나 등 풀스크린 화면 공통): 맨 왼쪽 **정사각 아바타(초상 · 노란 테두리)** → 바로 오른쪽 **전투력(칼 아이콘 + 주황 큰 숫자)** → **골드 pill(코인 아이콘 + 숫자 + 초록 ⊕)** → **보석 pill(다이아 아이콘 + 숫자 + 초록 ⊕)**. 프레임 맨 위에서 3.7% 띄움. 전투 HUD 에는 없다.
- **팝업**: 어두운 반투명 배경 위 **둥근 회색-갈색 패널** · 제목은 패널 위에 **리본/명판**(가운데) · 하단 프레임 밖 가운데 **«TAP TO CLOSE»** 흰 글자(닫기 X 버튼 없음 · 배경 탭으로 닫힘). 보상 팝업(출석·데일리 기프트)은 **노란 리본** + 패널 아래 오른쪽에 리본 꼬리.
- **버튼**: 주 버튼 = **주황(#F5A623 계열) 넓은 사각 · 굵은 검정 글자**(START · Open · Upgrade · Equip · Go · Enter · Challenge) · 보조 = **회색**(Unequip · Fuse · Upgrade All · Quick Equip) · 정보/광고 = **파랑**(Auto · 광고 클래퍼 버튼). 가격은 버튼 안에 «아이콘 + 숫자» 한 줄.
- **하단 탭 바 5칸**: 상점(천막) · 장비(투구) · 전투(칼 X) · 스킬(카드) · 주먹 — 현재 탭은 **위로 살짝 솟고 밝은 배경 + 라벨**. 빨간 ! 알림 점은 탭 오른쪽 위. 우리 탭 = 상점·장비·전투·탤런트·펫(순서 그대로 · 아이콘 자리만).
- **칸(장비/스킬 아이템)**: 등급색 **사각 프레임**(파랑=일반 · 보라=에픽 · 초록=합성 가능 표시) · 왼쪽 위 **부위 소아이콘** · 왼쪽 아래 **«+N» 노란 배지** · «Equipped» 는 칸 가운데 흰 글자 · 스킬 칸은 위에 **«Lv. N»** 배지 + 아래 **주황 진행바(«8/9»)**.
- **섹션 제목**: 가운데 정렬 흰 굵은 글자 + 양옆 가는 선(«Gem» · «Gold» · «Rewards»).
- **질감 3종(T72 · 주인 2026-09-06)**: 레퍼런스는 ① 풀스크린 배경·팝업·특별 상품 카드에 **`Pattern_01_256` 무늬**가 은은하게 깔려 있고(01 로비는 초록보다 어두운 칼 무늬 · 09 상점은 어두운 회색보다 밝은 무늬 · 로비는 오른쪽 위로 천천히 흐름) ② 상품·보상 아이콘 뒤에 **`Effect_Light_01_512` 빛살**이 천천히 시계방향으로 돌며 ③ 패널·버튼·카드·띠가 **위 밝고 아래 어두운 그라데이션** 색감이다. 우리 쪽은 `UiKit.PatternBg(host, tint)`(RawImage «Pattern» · 한 타일 **12.5s** · Ink/White **α 3/255**) · `UiKit.LightBehind(cell, icon)`(«LightMask/Light» · 한 바퀴 16s · 아이콘 × 1.9 · **α 68/255** · RectMask2D 로 칸 안) · `UiKit.Gradient(rt, top, bottom)`(«GradientTop/Bottom» · 흰 +12% / Ink −18%) 로 넣는다 — **세 수치는 주인 확정(2026-09-07 «패턴 255 중 3 · 빛살 255 중 68 · 패턴 속도 2배»)**. **버튼은 `UiKit.Button` 이 한 곳에서** 배경 그림 «안»에 아래 어둠 한 장(`ui.btnGradient`)을 덧대므로 화면 코드가 따로 부르지 않는다(레퍼런스 06 «Forge» · 13 «Summon» 처럼 위 밝고 아래 어둡다) — 전부 unscaled · 전투 월드에는 안 깐다. 색·굵기는 점수 밖이지만 무늬·빛살·그라데이션 «있음/없음» 은 화면 묶음(T63/T69/T72)이 끝난 화면부터 §5 감점 사유(항목당 −0.5). **공통 팝업(`UiKit.Popup`)은 상자 안 패턴을 한 곳에서 받는다**(T72 2단계 · 조각의 «Bg» 바로 위 · 둥근 모서리 안쪽 10px) — 팝업 화면은 따로 깔지 않는다.
